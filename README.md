# dream-compression.py
Dream Compression Engine: a weird research-ish project asking "how little info can represent a world?" Uses latent compression, LSTMs, motion-aware learning, fitness tracking and Kalman filtering to predict/reconstruct future states. Currently torturing a a bouncing ball. Also side-note I'm surprised that github is supporting vibe-coding, like it's extremely crazy, like all of our files are going to be fed to LLM(s).
